# BRO'GATCHI VIRTUAL PET SUITE
**Standalone Desktop & Mobile Companion Application**

A dedicated retro-style virtual companion pet featuring 7 custom-animated companion pets, 9 high-fidelity themes, an interactive arcade shop, mini-games, and IRL habit tracking.

---

## Features

* **7 Pixel Companion Pets**:
  - **🧔 Bro Ryan**: The classic gamer conspiracy bro.
  - **🐶 Cyber K-9**: Robotic companion dog with antenna tail and visor eyes.
  - **🐱 Neko Cat**: Cute lucky calico cat with whiskers and golden bell collar.
  - **🐲 Pixel Drake**: Mythical mini emerald dragon with flapping wings and smoke puffs.
  - **🐸 Ops Frog**: Spec-ops tactical frog with red bandana and big curious eyes.
  - **🛸 Cosmic Xeno**: Friendly alien buddy with pulsating star antennae and hover saucer glow.
  - **👻 Boo Ghost**: Float-bobbing translucent spirit with blushing pink cheeks.

* **9 High-Fidelity Room Backgrounds**:
  - **🛋️ Vanilla Lounge**: Clean cozy retro console aesthetic.
  - **🎮 RGB Gamer Room**: Deep indigo with ambient glowing violet/blue LEDs.
  - **☢️ Area 51 Bunker**: Military radar green phosphor grid.
  - **🌆 Cyberpunk 2077**: Dark violet skyline with neon cyan/magenta grid.
  - **🌌 Cosmic Space**: Deep space starfield with purple nebula clouds & twinkling stars.
  - **🌅 Retro Synthwave**: 80s Outrun sunset with glowing wireframe terrain.
  - **🌸 Sakura Garden**: Twilight cherry blossom garden with serene Japanese aesthetic.
  - **🏰 8-Bit Dungeon**: Dark stone castle dungeon bricks with warm flickering torchlight.
  - **🏖️ Pixel Beach**: Tropical sunset beach with warm coral skies and ocean wave gradients.

* **Arcade & Customization Shop**:
  - Adopt and switch any of the 7 companion pets instantly.
  - Switch room backgrounds on the fly.
  - Equip collectible hats (🧢, 👑, 🛸).
  - Purchase auto-mining rigs.

## Launching Bro'gatchi

Double-click `START-BROGATCHI.bat` or run:
```bash
npm run dev
```

## Building for Production

```bash
npm run build
```
