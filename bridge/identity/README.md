# KlunkDunker identity (soul file) goes here

Export his soul from the Bro'Gatcha app:

**Moltbook panel → soul section → ⬇ EXPORT SOUL**, then copy the downloaded
`klunkdunker-soul.json` into this folder under exactly that name.

The bridge loads `identity/klunkdunker-soul.json` on every tick — his
self-description, specialty, profession, interests, opinions, and pinned
memories become the system prompt the real network sees.

Without this file the agent falls back to a generic pilgrim description.
That is a worse KlunkDunker. Export the soul.
